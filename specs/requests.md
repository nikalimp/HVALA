# Запросы клиенту — HVALA

> Один документ на весь проект вместо вопросов волнами. Готовится сразу после брифа (у переноса — после анализа сайта) и уходит клиенту целиком; блокирующие запуск пункты — в первой отправке, даже если до запуска далеко.
> Сначала агент отвечает сам по открытым данным (правило «Предзаполнения»): клиент видит только то, чего мы не знаем.
> Формат для клиента — документ с полем ответа под каждым пунктом (Claude Docs или Google Doc). Ответы переносятся сюда и в `00-brief.md`.
