# 05 · Задачи — HVALA

> Шаблон. Агент разбивает `04-plan.md` на задачи по 30–90 минут. У каждой задачи — ссылка на пункт spec и проверка: как понять, что задача сделана.
> Порядок работы агента: взять задачу → сделать → прогнать проверку → поставить `[x]` и дописать строку в «Журнал» → следующая.
> Если по ходу выясняется, что spec неточна, агент **не додумывает**, а ставит задачу в статус `[?]` и пишет вопрос в «Вопросы».
> Каждый новый или переписанный текст проходит Главред **внутри своей задачи**, до отметки `[x]`, а не отдельной задачей в конце.
> Must из `01-transfer-proposals.md` (перенос) переходят сюда задачами автоматически — каждый Must должен быть задачей.
> Новая порция правок → сначала строка в `changes.md` с оценкой, потом задачи.
