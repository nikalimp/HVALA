## 2. Семантика
Источники: Яндекс Вордстат, подсказки Яндекса и Google, блок «Похожие вопросы», вопросы из брифа, Keys.so / Serpstat при наличии доступа.

### Кластеры
| Кластер | Главный запрос | Частотность / мес | Доп. запросы | Интент (купить / узнать / сравнить) | Страница |
|---|---|---|---|---|---|
| | | | | | → заполняется в 02-spec |

Правила кластеризации:
- одна коммерческая страница на кластер с общим интентом;
- информационные запросы «как», «сколько», «что лучше» → статья или блок FAQ;
- запросы с городом → отдельные страницы, только если у клиента реально есть точки в этих городах.
